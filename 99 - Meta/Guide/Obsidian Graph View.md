# How I Use The Obsidian Graph View
![](https://i.ytimg.com/vi/Z8WIALfgaA4/maxresdefault.jpg)



## Intro [(00:00:00)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=0s)
- The graph view in [Obsidian (software)](https://en.wikipedia.org/wiki/Obsidian_(software)) is more than just a visual representation of notes and can be used in various ways [(00:00:09)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=9s)
- The video will cover the features of the graph view and three main use cases that make it an indispensable page of an Obsidian vault [(00:00:17)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=17s)

## What The Graph View Can Do For You [(00:00:20)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=20s)
- The graph view has four sections: filters, groups, display, and forces [(00:00:32)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=32s)
- Filters can be used to filter notes by tags, paths, file names, lines, and sections [(00:00:41)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=41s)
- The "existing files only" filter can be toggled off to show notes that don't yet have any content [(00:02:23)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=143s)
- [Orphan](https://en.wikipedia.org/wiki/Orphan) notes are notes that don't have any links, and can be filtered separately [(00:02:32)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=152s)
- Groups can be used to add color to the graph view based on filters [(00:02:51)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=171s)
- Display options include showing the direction of links, text fade, note size, and length thickness [(00:03:20)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=200s)
- Forces can be used to adjust the layout of the graph view, including link distance [(00:04:18)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=258s)

## My Use Case 1 [(00:04:36)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=276s)
- The graph view's usefulness is relative to the size of the vault, with larger and more complex vaults benefiting more from the feature [(00:04:42)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=282s).
- Assigning colors to different groups using the file name as a filter can help distinguish between different parts of the vault [(00:05:06)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=306s).
- There's no limit to the amount of groups that can be created, making the imagination the only limitation [(00:05:47)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=347s).

## Filtering and Hiding Content [(00:05:52)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=352s)
- [Obsidian (software)](https://en.wikipedia.org/wiki/Obsidian_(software)) can be set to hide certain content by adding a minus sign at the beginning of a filter [(00:06:10)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=370s).
- Multiple filters can be combined to exclude multiple types of content [(00:06:47)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=407s).
- A start note can be used to store a filter equation, making it easier to access and apply the filter [(00:07:13)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=433s).

## Default Filter Feature [(00:07:23)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=443s)
- There is currently no native feature in Obsidian to set a default filter for the graph view [(00:07:23)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=443s).
- A workaround is to use a start node to store the filter equation and easily access it [(00:07:54)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=474s).

## My Use Case 2 [(00:08:20)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=500s)
- Obsidian's graph view allows for a more intuitive way to pick up where one left off, regardless of the vault size [(00:08:48)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=528s).
- The "orphans" option can be used to find and connect unlinked notes, making the note-taking system more organized [(00:09:02)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=542s).
- A monthly reminder can be set to review [Orphan](https://en.wikipedia.org/wiki/Orphan) notes and make connections, which can spark creativity and open up new ideas [(00:09:27)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=567s).
- Tagging orphan notes with a specific tag, such as "orphan note", allows for easy filtering in the graph view [(00:11:00)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=660s).
- Toggling off "existing files only" can help pick up where one left off by showing empty notes with connections [(00:11:27)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=687s).

## My Use Case 3 [(00:12:20)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=740s)
- The local navigation use case involves using the graph view on a note page to visualize connections between notes [(00:12:34)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=754s).
- The local graph view can be accessed by pressing command p, typing in "local graph," and selecting the "open local graph" option [(00:12:48)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=768s).
- The local graph view provides four additional options not seen on the main graph view: depth, incoming links, outgoing links, and neighbor links [(00:13:04)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=784s).

## Local Graph View Options [(00:13:12)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=792s)
- The depth option allows users to increase the number of layers shown in the graph view, providing a more macro view of the connections [(00:13:14)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=794s).
- Incoming links show which notes have links to the current note [(00:14:11)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=851s).
- Outgoing links show links that are outgoing from the current note [(00:14:39)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=879s).
- Neighbor links show connections between notes that are connected to the current note [(00:14:57)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=897s).

## Benefits of Local Graph View [(00:15:46)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=946s)
- The local graph view substitutes for the traditional file explorer, providing a visual representation of note connections [(00:15:51)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=951s).
- It is especially useful for fiction writers or [Doctor of Philosophy](https://en.wikipedia.org/wiki/Doctor_of_Philosophy) candidates who need to see multiple connections between notes [(00:15:32)](https://www.youtube.com/watch?v=Z8WIALfgaA4&t=932s).
