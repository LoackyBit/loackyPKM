# Google Deep Research

## 1
```
If I want to learn {argument}. Would you please create a Learning Roadmap for me?
```
# Cursor
## 2
```
This the a learning roadmap report. I need you to do the following:

Step1: Based on the learning roadmap, create a list of markdown files for each topic.
Step2: For each topic file, write an introduction and a list of knowledge points. Each knowledge points tittle should be written in [[ ]].
```
## 3
```
Add your created file name list in the original '{name of the roadmap}.md' , place them under each topic related. Remember use [[ ]] to quote the file name
```

in italiano:

# Google Deep Research

## 1
```
Se voglio imparare {argomento}. Potresti creare una Roadmap di Apprendimento per me?
```

# Cursor
## 2
```
Questo è il rapporto della roadmap di apprendimento. Ho bisogno che tu faccia quanto segue:

Passo 1: Basandoti sulla roadmap di apprendimento, crea una lista di file markdown per ogni argomento.
Passo 2: Per ogni file di argomento, scrivi un'introduzione e una lista di punti di conoscenza ordinati per importanza. Il titolo di ogni punto di conoscenza deve essere scritto tra [[ ]].
Passo 3: Per ogni punto di conoscenza, crea una file markdown
```

## 3
```
Aggiungi la lista dei nomi dei file che hai creato nel file originale '{nome della roadmap}.md', posizionandoli sotto ogni argomento correlato. Ricorda di usare [[ ]] per citare il nome del file.
```
